# Hình nền iFruit

Upload tối đa 10 ảnh WebP vào thư mục này. Dùng đúng tên `wallpaper-01.webp`, `wallpaper-02.webp`, …, `wallpaper-10.webp`. Khung ngang 16:9 phù hợp với màn hình điện thoại.

`wallpaperIndex` đếm từ 1 đến 10. Slot chưa có ảnh hiện nền mặc định. Sau khi upload, cập nhật các URL ghim commit trong prompt sang commit mới chứa ảnh.
